# CVPR_2024

本仓库集中保存 **CVPR 2024 冠层图** 与 **CVPR 2024 叶面斑块** 研究方向的原始 GitHub 参考项目。

来源：`开源代码清单(8).md` 与 `开源代码清单(9).md`。按完整的原始 `owner/repo` 地址去重，每个项目沿用原仓库名称建立单独文件夹。

**去重统计：** 69 条项目记录，其中 6 个跨研究方向重复（FADC、UniRepLKNet、RISNet、RepViT、SHViT、FreeKD），保留 **63 个独立项目**。经许可证检查，**38 个**计划导入有再分发许可的源码，**25 个**仅保存来源链接。

> 这些是集中管理的源码快照与链接，不是 GitHub 官方意义上的 Fork，也不包含上游原始 Git 提交历史。请以每个项目自己的许可证、论文版本与原始来源为准。
